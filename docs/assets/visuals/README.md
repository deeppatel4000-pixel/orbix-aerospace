# ORBIX visual asset register

The register of every raster image in `public/`, with source, licence and verification date, is
[`../image-provenance.md`](../image-provenance.md). Add new images there before using them.

Code-native graphics (SVG diagrams and the brand mark components in `src/components/brand/`) are
authored in this repository under the project licence.

## Environment plates

The four files in `public/images/environments/` were produced with an AI image generator (records in
[`generated-environments.md`](./generated-environments.md)). ORBIX no longer uses AI-generated
images; these files are unverified and scheduled for removal together with their components.
